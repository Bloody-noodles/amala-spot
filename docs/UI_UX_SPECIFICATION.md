## Behaviour
- Sticky navigation and accessible mobile navigation.
- Smooth anchor navigation and restrained reveal motion.
- Marquee must respect reduced motion and not create keyboard traps.
- Menu filters and cart controls must be keyboard operable.
- Voice is optional; typed assistant remains available.
- Mobile prioritises readable content, touch targets, and hierarchy.

## Current foundation
The first page pass establishes the palette, hero, ticker, editorial sections, menu preview, assistant teaser, and footer. Dynamic data, mobile navigation behaviour, and several interactive features remain to be implemented.
