# Food image asset audit

**Date:** 26 November 2026

The menu has forty-one locally stored food and drink photos: Amala, Gbegiri & Ewedu; Amala & Ewedu; Eba & Ogbono; Nigerian Jollof Rice; Nigerian Fried Rice; Egusi Soup; Pounded Yam & Egusi; Efo Riro; Ewedu; Peppered Asun; Beef Suya; Assorted Meat Pepper Soup; Dodo; Moi Moi; Beans Porridge; Chilled Zobo; Chapman; Bottled Water; Almond Drink; Drinking Yoghurt; Tiger-Nut Milk; Hollandia Yoghurt; Chivita Active; Chivita 100%; Sprite Can; Coca-Cola; Fanta Orange; Sprite; 7UP; Pepsi; Pepsi Can; Coca-Cola Can; Fanta Orange Can; Maltina; Malta Guinness; Greek Yoghurt; Five Alive Pulpy; Five Alive Berry Blast; Kunu; 7UP Can; and Ofada Rice & Ayamase. Their source, creator, rights, menu mapping, and crop handling are recorded in [`public/images/menu/ATTRIBUTION.md`](../public/images/menu/ATTRIBUTION.md). Product-specific `object-fit: contain` presentation preserves the Pepsi bottle, both Five Alive bottles, Pepsi, Coca-Cola, Fanta, Sprite and 7UP cans, and the Hollandia and Chivita cartons. The Maltina image is cropped to feature two labeled cans; the Pepper Soup crop keeps the bowl and assorted meat centered. Other menu photos use `object-fit: cover`. Other graphic markers remain placeholders and must not be treated as menu photography.

## Image coverage

**Count:** all 41 fallback entries have mapped local photos, nonempty files, alt text, and matching attribution rows. A SHA-256 comparison of the 41 local menu image files found no byte-identical duplicate files. The user confirmed ownership and approved use of the Ofada and Berry Blast photos on 26 November 2026; both are Pinterest downloads and their original pin URLs were not supplied. The live Supabase catalogue may differ and requires an authorized data audit before this list can be treated as exhaustive for production data.

## Remaining image work

1. Verify the complete live catalogue against authorized non-production Supabase data.
2. Inspect desktop/mobile crops and accessibility text for every asset, including the two newly mapped owner-provided photos.
The current Supabase `menu_items` schema and admin menu API do not expose image fields, and admin does not edit menu imagery. Local image mappings are maintained with the fallback menu data and preserved when API records omit images. The plan’s conditional image-metadata/admin-workflow change is therefore not applicable to the current admin capability; revisit if image editing is added.
